# Mockups

Animated design prototypes for the three channels, all in the "Flow + Pulse" layout. They're the source of truth for look, copy and motion. See section 2 of `../PROMPT.md` for how to read the format.

| File | Channel | Release |
|---|---|---|
| `D-earthquakes.dc.html` | Earthquakes (USGS) | v1 |
| `F-wikipedia.dc.html` | Wikipedia pulse (Wikimedia EventStreams) | v1.1 |
| `E-exploited-vulns.dc.html` | Exploited vulnerabilities (CISA KEV + NVD) | v1.2 |

All data in these files is fake demo data (random generators, `DEMO-2026-xxxxx` IDs, time-lapse for earthquakes and vulnerabilities). Wikipedia runs at real speed.
